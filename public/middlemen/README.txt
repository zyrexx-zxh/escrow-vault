PROFILE PHOTOS
==============
Put each middleman's photo in this folder, named after the middleman's NAME in lower-case:

  beam.jpg     cold.jpg     cool.jpg     cry.jpg      cupid.jpg
  top.jpg      faiq.jpg     fame.jpg     ja.jpg       laugh.jpg
  nine.jpg     nova.jpg     scholar.jpg  sprint.jpg   streaky.jpg
  tweak.jpg    shib.jpg     wave.jpg     will.jpg

- .jpg is tried first, then .jpeg, .png and .webp.
- Names are lower-case (Render/GitHub are case-sensitive): "Top" -> top.jpg, "Shib" -> shib.jpg.
- Note the file uses the NAME, not the Telegram username: "cry" is cry.jpg (not melon.jpg),
  "Top" is top.jpg (not drift.jpg), "ja" is ja.jpg (not wrosen.jpg).
- Square or portrait photos, around 600x800 px, under ~200 KB each load fastest.
- If a file is missing, that card just shows a tinted placeholder.
